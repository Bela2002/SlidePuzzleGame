# 🧩 Slide Puzzle Game

A classic **Slide Puzzle Game** implemented using **Java Swing**.  
This game provides a graphical user interface (GUI) that allows users to interact with the puzzle visually and intuitively.

---

## 📖 About

This project was developed using the **Java Swing UI framework** to create an interactive slide puzzle game.  
The GUI handles all valid interactions with the puzzle and provides real-time visual feedback to the user regarding tile movements and game status updates.

---

## 🎮 Features

- 🎯 Interactive 4x4 (or more) tile-based sliding puzzle
- 🧠 Logical tile movements with validation
- ⏱️ Play with **limited time**
- 🔢 Play with **limited number of moves**
- 👤 View current player details
- 🏆 See the **Best Player** (based on time)
- 🔁 Shuffle, Reset, and Replay functionality
- 📝 On-screen **instructions** for players
- 🎉 Victory detection and game over message

---

## 📋 Instructions

How to Play:

🎯 Click tiles adjacent to the empty space to move them.

⏱️ Complete the puzzle within the time limit when play with limited time.

🔢 Don’t exceed the maximum number of moves when play with limited moves.

🏁 Solve the puzzle to win and register your name as the best player!

🔄 Use the new game option to start over.

📊 Check your performance and compare it to the best player.
